# مفتاح توقيع MyNotes

`mynotes.jks` يوقّع كل نسخة يبنيها GitHub Actions بنفس المفتاح، لذلك يُثبَّت كل APK جديد كتحديث
فوق النسخة الموجودة دون مسحها. لا تحذف هذا الملف ولا تغيّره، وإلا ستحتاج إلى مسح التطبيق مرة أخرى.

ملاحظة: المستودع عام، فالمفتاح مكشوف (اختيار صاحب المشروع). هذا مقبول لتطبيق شخصي يُثبَّت يدويًا.
